*auto_convert.txt*  Context-aware LLM input conversion for Vim

==============================================================================
1. Overview                                                     *auto_convert*

Auto Convert checks recently changed lines every three seconds and when Insert
mode ends. It uses nearby context to convert romanized or phonetic input into the
intended language and writing system. Japanese romaji, Chinese pinyin, Korean
romanization, and similar input methods can be handled without limiting the
plugin to one language. Changes are applied only to the Vim buffer; Auto Convert
never writes the edited file.

==============================================================================
2. Requirements                                         *auto_convert-requirements*

- Vim with +job and +channel
- curl
- OPENAI_API_KEY, or DEEPSEEK_API_KEY when using DeepSeek

With pathogen: >
  git clone https://github.com/hedachi/vim-auto-convert.git ~/.vim/bundle/vim-auto-convert
<
Restart Vim after installation.

==============================================================================
3. Privacy                                                   *auto_convert-privacy*

Auto Convert sends changed lines and nearby context to the selected API
provider. Do not use it for text that must not leave your computer or
organization.

API keys are read from environment variables. The default log is
~/.vim/auto_convert.log and records timing, status, line numbers, and errors
without recording edited text or instructions.

==============================================================================
4. Commands                                                   *auto_convert-commands*

                                                      *:AutoConvertToggle*
:AutoConvertToggle        Enable or disable automatic conversion.

                                                         *:AutoConvertNow*
:AutoConvertNow           Check current changes immediately.

                                                      *:AutoConvertStatus*
:AutoConvertStatus        Show the current state and most recent result.

==============================================================================
5. Settings                                                   *auto_convert-settings*

Set options in vimrc before the plugin is loaded: >
  let g:auto_convert_enabled = 1
  let g:auto_convert_interval = 3000
  let g:auto_convert_provider = 'luna'
  let g:auto_convert_model = 'gpt-5.6-luna'
  let g:auto_convert_effort = 'none'
  let g:auto_convert_context = 8
  let g:auto_convert_max_lines = 40
  let g:auto_convert_target_language = 'auto'
  let g:auto_convert_logfile = expand('~/.vim/auto_convert.log')
<
Use 'deepseek' for g:auto_convert_provider and set DEEPSEEK_API_KEY to use the
DeepSeek endpoint. g:auto_convert_deepseek_model changes its model name.
