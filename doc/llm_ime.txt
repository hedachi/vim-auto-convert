*llm_ime.txt*  Context-aware LLM input conversion for Vim

==============================================================================
1. Overview                                                     *llm_ime*

LLM IME checks recently changed lines every three seconds and when Insert mode
ends. It uses nearby context to convert romanized or phonetic input into the
intended language and writing system. Japanese romaji, Chinese pinyin, Korean
romanization, and similar input methods can be handled without limiting the
plugin to one language. Changes are applied only to the Vim buffer; LLM IME
never writes the edited file.

==============================================================================
2. Requirements                                         *llm_ime-requirements*

- Vim with +job and +channel
- curl
- OPENAI_API_KEY, or DEEPSEEK_API_KEY when using DeepSeek

With pathogen: >
  git clone https://github.com/hedachi/vim-llm-ime.git ~/.vim/bundle/vim-llm-ime
<
Restart Vim after installation.

==============================================================================
3. Privacy                                                   *llm_ime-privacy*

LLM IME sends changed lines and nearby context to the selected API provider.
An empty [] request sends up to 40 nearby lines to OpenAI. |:Ai| sends the
entire current buffer. Do not use these features for text that must not leave
your computer or organization.

API keys are read from environment variables. The default log is
~/.vim/llm_ime.log and records timing, status, line numbers, and errors without
recording edited text or instructions.

==============================================================================
4. Commands                                                   *llm_ime-commands*

                                                      *:LlmImeToggle*
:LlmImeToggle        Enable or disable automatic conversion.

                                                         *:LlmImeNow*
:LlmImeNow           Check current changes immediately.

                                                      *:LlmImeStatus*
:LlmImeStatus        Show the current state and most recent result.

                                                                 *:Ai*
:Ai {instruction}     Apply an AI editing instruction to the entire buffer.

Write [] in a changed line to ask the assistant to place its answer inside the
brackets. The answer job runs separately from typo correction.

==============================================================================
5. Settings                                                   *llm_ime-settings*

Set options in vimrc before the plugin is loaded: >
  let g:llm_ime_enabled = 1
  let g:llm_ime_interval = 3000
  let g:llm_ime_provider = 'luna'
  let g:llm_ime_model = 'gpt-5.6-luna'
  let g:llm_ime_effort = 'none'
  let g:llm_ime_ask_model = 'gpt-5.6-sol'
  let g:llm_ime_ask_effort = 'none'
  let g:llm_ime_context = 8
  let g:llm_ime_max_lines = 40
  let g:llm_ime_target_language = 'auto'
  let g:llm_ime_logfile = expand('~/.vim/llm_ime.log')
<
Use 'deepseek' for g:llm_ime_provider and set DEEPSEEK_API_KEY to use the
DeepSeek endpoint. g:llm_ime_deepseek_model changes its model name.
